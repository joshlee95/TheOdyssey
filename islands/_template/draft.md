# 나의 섬 — 작성 질문지

> 이 파일을 복사해서 편하게 써 주세요. 문장이든 메모든 괜찮아요.
> 빈칸이 있어도 AI가 채워 주지만, **AI가 지어낸 부분은 review.md에 따로 정리**되니 확인하고 고치면 됩니다.
>
> ```bash
> cp -r islands/_template islands/my-island   # 폴더 이름 = 섬 id (영문 소문자·하이픈)
> # draft.md 작성 후
> npm run island:build -- my-island           # → island.yaml + review.md 생성 + 검증
> ```
>
> ⚠️ 이 파일에는 섬의 **비밀**이 들어갑니다. 다른 친구에게 보여 주지 마세요.
